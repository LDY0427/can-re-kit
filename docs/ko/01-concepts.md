# 1. 개념 — 버스에서 값이 오는 두 가지 길

[English](../01-concepts.md)

## CAN 프레임

CAN 프레임 하나 = **ID**(11비트 또는 29비트) + **데이터 0~8바이트**. ID가 낮을수록 우선순위가 높다. 누가 보냈는지는 프레임에 없다. ID로 짐작할 뿐이다.

받는 쪽 중 하나라도 정상으로 받으면 **ACK**를 준다. ACK를 줄 장치가 아무도 없으면 보낸 쪽은 같은 프레임을 계속 다시 보낸다. 오토바이처럼 ECU 하나만 남은 버스에서 이 일이 생긴다(4장).

흔한 속도: 500 kbps(대부분의 진단·파워트레인), 250 kbps(트럭·일부 오토바이), 125 kbps, 1 Mbps.

## 값이 오는 두 가지 길

| | 상시 프레임 (broadcast) | 요청·응답 (diagnostic) |
|---|---|---|
| 어떻게 | ECU가 정해진 주기로 스스로 보낸다. 계기판·ABS가 받아 쓴다 | 진단기가 물어볼 때만 답한다 |
| 찾는 법 | 듣기만 해도 보인다. 바이트가 무엇을 따라 움직이는지 본다 | 요청을 보내야 한다. 어떤 번호에 답하는지 훑는다 |
| 장점 | 빠르다(10~100 ms 주기), 버스에 아무것도 안 보낸다 | 표준 항목은 식이 공개돼 있다 |
| 단점 | 식이 비공개. 계기판·ABS가 없으면 아예 없을 수 있다 | 요청 장치가 필요. 초당 답 수에 한계가 있다 |
| 결과물 | DBC 파일 | 요청 목록과 식(이 저장소의 `diag_signals`) |

**먼저 듣고, 아무것도 없으면 묻는다.** 우리 차(오토바이 엔진 ECU 단독)는 엔진 정지 상태에서 200초 동안 상시 프레임이 0개였다. 그래서 요청·응답으로 갔다.

## 진단 요청의 구조 (ISO 15765-4, OBD-II on CAN)

- 요청 ID: `7DF`(모든 ECU에게) 또는 `7E0`~`7E7`(특정 ECU에게). 응답 ID: `7E8`~`7EF`(요청 ID + 8).
- 프레임 데이터 첫 바이트는 **길이**(ISO-TP). `canre req 21 21`이라고 쓰면 실제로는 `7DF  02 21 21 00 00 00 00 00`이 나간다. 길이 바이트는 도구가 붙인다.
- 응답 첫 바이트 = 요청 서비스 + `0x40`. `21 21` 요청 → `61 21 xx xx`. 뒤의 `xx xx`가 값이다.
- 거부는 `7F <서비스> <이유 코드>`. `12` = 그런 번호 없음, `11` = 그런 서비스 없음, `22` = 지금 조건에서 안 됨, `33` = 보안 접근 필요, `78` = 기다려(곧 답함).
- 응답이 7바이트를 넘으면 여러 프레임으로 온다(First Frame → 요청 쪽이 Flow Control → Consecutive Frames). 고장 코드 목록이 흔한 예. `canre`가 처리한다.

## 서비스 번호

| 서비스 | 이름 | 내용 |
|---|---|---|
| `01` | OBD 현재 값 | 표준 PID. `01 00`은 "1~20번 중 뭘 지원하나" 비트맵 |
| `03` `07` `0A` | 고장 코드 | 저장 / 이번 주행 / 영구 |
| `09` | 차량 정보 | `09 02` = VIN(공유 전 지울 것) |
| `21` | KWP2000 지역 번호 읽기 | 제조사 전용 값. 1바이트 번호 |
| `22` | UDS 식별자 읽기 | 제조사 전용 값. 2바이트 번호 |
| `19` | UDS 고장 정보 | 최신 ECU의 고장 코드 |

**표준 PID는 자(ruler)다.** 식이 공개된 표준 값(수온 `01 05`, 흡기압 `01 0B`, 스로틀 `01 11`)을 같이 읽어 두면, 제조사 번호의 뜻과 식을 그 자에 대어 찾을 수 있다. 5장의 핵심이다.

## K-line은 다르다

많은 오토바이(특히 2010년대 이전 일본 브랜드)는 CAN이 아니라 **K-line**(ISO 9141 / ISO 14230 KWP2000, 한 가닥 선)을 쓴다. 이 도구의 CAN 기능은 K-line에 쓸 수 없다. 서비스 번호(`21`, `1A` 등)와 해석 방법(5·6장)은 같다. 버스 종류부터 확인하는 법은 3장.
